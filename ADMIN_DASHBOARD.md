# ADMIN DASHBOARD

## Dashboard
- Active rounds
- Pending payments
- Confirmed selections
- Current collected amount
- Recent winners
- Recent activity

## Draw management
Admin can:
- Create round
- Configure price
- Open/close round
- View numbers
- View selections
- Resolve payment issues
- Trigger draw only when permitted by business rules
- Publish result

## Payment verification
Every approval must record:
- Admin
- Timestamp
- Payment reference
- Amount
- Related player
- Related draw
- Related selection

## Audit
Sensitive actions must create audit records.
